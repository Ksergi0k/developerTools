# Developer tools
Кастомная панель администратора с инструментами разработчика:
- Настройка логирования
- Просмотр логов
- Изменение кастомных стилей
- Консоль сервера
- Генератор паролей
- Активные подключения
- Статистика вызовов
- Заметки
- Интерактивный блокнот

## Инструкция по установке
1. Загрузитев все файлы репозитория в директорию на сервере Платформы, рекомендуем использовать путь "./apps/developerTools"
2. Создайте контекст "приложение" в целевом пользователе, и в качестве пути, укажите директорию из п.1
3. Выполните действие "Update" ("Обновить") на созданном приложении
4. Один раз запустите вручную дашборд "users.[user].dashboards.developerTools" ("SberMobile Developer Tools (developerTools)"). При первом запуске в пользователе создастся автозапуск и необходимые устройства

## Дополнительные утилиты

### modelTools

createVariable - создание переменной с передачей имени и формата, поддерживает предустановленные переменные;

getFormat - получение формата таблицы в виде таблицы;

updateFormat - смена формата указанной колонки с копированием данных;

sendFeedback - вывод системного уведомления пользователю;



### userTools

switchResources - включение/выключение неиспользуемых ресурсов пользователя

showDevicesTypes - включение/выключение отображение типа всем устройствам
